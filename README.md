# Nivram

Nivram is an empirical systems-engineering programme for building
human–AI-agent systems that can do things neither humans nor agents
can do alone.

The project studies mixed human–agent adaptive systems through working
systems, controlled experiments and falsifiable hypotheses.

Its working method is empirical first, theory second:

observe → hypothesise → build → experiment → evaluate → learn → revise
