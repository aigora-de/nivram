# Individuality is not a persona

**When:** evaluating individuality, fungibility, identity or path dependence.

Do not mistake names, prompting, style or stochastic variation for individual
trajectories. Look for measurable, durable, consequential behavioural differences
after differentiated experiences, and test with common evaluation settings,
cloned checkpoints, memory interventions and shuffled histories.

**Limit:** persona can be a useful experimental control or baseline; it is not
itself proof or disproof of individuality.
